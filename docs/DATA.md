# 데이터 운영 안내

## 사용 흐름

- **오늘의 국회**: 아르고스 ‘법률과 이슈’의 업데이트순 상위 20개를 원본 순서대로 표시합니다. 첫 항목은 대표 이슈, 다음 4개는 브리핑, 아래에서 20개 전체를 탐색합니다. 법률명·이슈 검색을 지원합니다.
- **새로고침**: 브라우저 새로고침 또는 ‘최신 목록 새로고침’으로 아르고스 목록을 다시 조회합니다. 원본이 같으면 목록은 유지됩니다. 인기 순위나 임의 추천 순서가 아닙니다.
- **국회탐험**: 이슈·입법 기록·법률 이력·발의 의원 도형을 선택합니다. 모바일에서는 도형 아래 설명으로 이동합니다. 연혁, 의안의 제안일·처리 결과·공포일, 제안이유 원문과 공식 링크를 확인합니다.
- **의원의 업무노트**: 선택한 법률에서 확인된 대표발의 기록과 의원의 공식 소개 페이지를 제공합니다. 전체 의정활동 통계나 역량 점수로 표시하지 않습니다.
- **개인 낙서장**: 의원에 대한 생각과 법률에 대한 생각을 분리합니다. 임시 저장, 저장·수정·삭제·되돌리기, 텍스트 내려받기를 지원합니다. 같은 법률의 메모는 다른 의원 업무노트에서도 이어집니다.

## 자료의 범위와 표시

출처: [국회도서관 아르고스](https://argos.nanet.go.kr/main/fusionanalysis/lawIssueGuest.do), [국회 의안정보시스템](https://likms.assembly.go.kr/bill/main.do).

- 공개 페이지에서 사용하는 조회 요청을 서버에서 호출합니다. 로그인·API 키는 사용하지 않습니다. 공개 웹페이지와 조회 형식이 바뀌면 연결 부분을 수정해야 합니다. 보장된 외부용 API 계약을 전제로 하지 않습니다.
- 아르고스의 **AI 설명**은 별도 표시합니다. 정독이 독립적으로 사실 확인한 기사나 법률 해설이라고 표시하지 않습니다.
- 각 법률에서 아르고스가 최근 연결한 의안 **1건**을 읽고, 그 의안의 ‘대안에 연결된 원안’을 **최대 20건** 확인합니다. 모든 발의안·공동발의자·표결·출석을 수집한 것은 아닙니다.
- 대표발의 의원은 공식 의안 페이지의 대표발의 의원 영역에서만 연결합니다. 위원회·정부 제안자를 특정 의원으로 추정하지 않습니다. 확인된 의원이 없으면 빈 상태와 원문 링크를 제공합니다.
- 의안별 대안반영폐기·원안가결 등 실제 처리 결과를 유지합니다. 대표발의 사실을 곧바로 법률 개정의 단독 성과로 표시하지 않습니다.
- 법률 상세와 의안은 15분 동안 재사용하며 확인 시각을 표시합니다. 목록의 업데이트 날짜나 설명이 바뀌면 법률 상세를 다시 확인합니다.
- 원본 접속에 실패하면 `.runtime`의 마지막 확인본 또는 함께 제공된 `data`의 수집본을 보여주며, **마지막 확인본**과 확인 시각을 표시합니다. 처음 보는 법률에 저장 자료도 없으면 오류와 다시 시도 버튼을 제공합니다.
- 초기 수집본은 2026-10-08에 확인한 실제 자료입니다. 외부에 공개 배포한 서비스는 아닙니다.

## 개인 노트

노트는 현재 브라우저의 로컬 저장소(`jeongdok-private-v1:*`)에만 저장됩니다. 서버·의원·다른 사용자에게 전송되지 않습니다. 같은 컴퓨터라도 브라우저나 접속 주소(포트)가 다르면 저장 공간이 다릅니다. 브라우저 데이터를 삭제하면 지워지므로 ‘내 노트 내려받기’로 보관할 수 있습니다. 계정 동기화·인스타그램 재생·의원에게 질문 전송·공개 토론 기능은 이번 연결 버전에 포함되어 있지 않습니다.

## 서버와 수집본

개발·실행 서버는 같은 출처의 API를 제공합니다. 공개 배포 시 Node 서버 또는 이에 대응하는 API 서버가 필요합니다. 현재 서버는 이 컴퓨터에서만 접근하는 로컬 주소에 연결합니다.

수집본을 갱신하려면 `npm run snapshot`을 실행합니다. `data/`에는 공개 자료만 저장되며 개인 노트는 포함되지 않습니다. `.runtime/`은 자동 캐시이며 Git에서 제외합니다.
